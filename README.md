# precystorebackend

PrecyNails Luxury Press-On Nail Studio Backend API built with Node.js, Express, and Supabase PostgreSQL.

## Features
- Vendor Authentication (JWT)
- Product Management API
- Order Intake & Tracking API
- Expense Tracking API

## Setup & Environment
1. Clone the repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in Supabase credentials
4. Start the server with `npm run dev`
